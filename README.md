# Smart Inventory Management System using IoT and AI/ML

## Project Description
A low-cost system that tracks the stock of items automatically using IoT devices (ESP32, RFID reader and load-cell weight sensor) and predicts future demand with a Random Forest machine-learning model. It shows live stock on a web dashboard and sends low-stock alerts, so that college labs, departments and small shops always have the right items at the right time.

This repository contains the **Seminar Presentation and Project Initiation (SPI – 315003)** work: the seminar presentation, the SPI report and the 12 research papers studied.

## Tech Stack

| Layer | Technology |
|---|---|
| Microcontroller | ESP32 (built-in Wi-Fi) |
| Sensors | RFID Reader RC522 with RFID tags, Load Cell with HX711 amplifier, DHT11 (optional) |
| Firmware | C/C++ using Arduino IDE |
| Communication | Wi-Fi with HTTP / MQTT |
| Backend | Python 3.11, Flask (REST API) |
| Database | MySQL |
| Machine Learning | scikit-learn (Random Forest), pandas, NumPy |
| Frontend / Dashboard | HTML, CSS, JavaScript, Chart.js |
| Tools | Visual Studio Code, Git and GitHub |
