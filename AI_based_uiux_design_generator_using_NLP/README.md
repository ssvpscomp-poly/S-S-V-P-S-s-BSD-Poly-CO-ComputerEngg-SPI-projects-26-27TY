1.Project Title :- AI based ui-ux design generator using NLP

2.Descripitions :- An AI-based UI/UX design generator uses Natural Language Processing (NLP) to turn plain-text descriptions, such as “a clean login page with a dark theme,” into ready-to-use interface layouts, color schemes, and components. It interprets the user’s intent, applies design principles and accessibility standards, and produces editable wireframes or prototypes within seconds. This reduces design time, lowers the skill barrier for non-designers, and lets teams iterate on ideas quickly.
