1. Project title: Students Skill & Course Recomandation System 

2. Project description:
   The Student Skills & Course Recommendation System is a technology-based project designed to help students identify their skills, interests, and learning needs and recommend suitable courses according to their future goals.
Many students face difficulty choosing the right course because they may not know which skills they possess, which skills they need to improve, or which courses are relevant to their career interests. This system aims to simplify the decision-making process by providing personalized course recommendations.The system collects information such as students’ interests, existing skills, educational background, and career goals. It then compares this information with a database containing course details, required skills, learning objectives, and course levels. Based on this comparison, the system suggests courses that match the student’s profile and may help develop new skills.The system collects information such as students’ interests, existing skills, educational background, and career goals.
