ML-Based Resume Optimizer

Project Description

ML-Based Resume Optimizer is a proposed system designed to help job seekers improve their resumes according to specific job requirements. It uses OCR, Natural Language Processing (NLP), Machine Learning (ML), and LLM-based feedback to extract and analyse resume information.

The system processes resumes, identifies skills, education, and work experience, compares resume information with job descriptions, and provides matching results and suggestions for improvement.
